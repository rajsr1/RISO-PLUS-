# RISO-PLUS-
The main problem addressed by the Hospital Management System (RISO PLUS+) is the lack of a centralized,
efficient, and user-friendly platform to manage hospital operations for different stakeholders such as
administrators, receptionists, doctors, and billing staff. In many traditional hospitals, processes like patient
registration, appointment scheduling, room assignment, tracking admissions, and maintaining patient records
are often handled manually or through multiple separate systems. This leads to problems such as data
duplication, errors, delays in service, and difficulty in accessing accurate patient information when needed.
The proposed RISO PLUS+ system provides an integrated digital solution where all users can interact within
a single platform according to their roles. The admin can manage users, doctors, and departments; the
receptionist can register patients, schedule appointments, and assign rooms efficiently; the doctor can access
patient details, view appointments, and update medical records; and the billing staff can manage payments and
invoices. All data is stored in a centralized Microsoft SQL Server database, ensuring consistency, security, and
real-time access across all modules.
By using a structured database with proper relationships and implementing object-oriented programming
concepts in C#, the system minimizes redundancy and improves overall performance. This solution simplifies
hospital workflows, reduces manual workload, enhances coordination among different departments, and
improves the quality and speed of patient service. Ultimately, the Hospital Management System (RISO
PLUS+) provides a reliable and organized approach to handling hospital operations in a modern digital
environment.
